# 🐍 Python OOP Practice
Welcome to my **Python Object-Oriented Programming (OOP) Practice Repository!**

This repository contains my Python practice programs and mini-projects created while learning and improving my programming skills. It focuses on understanding OOP concepts through practical examples.

## 🚀 About This Repository

The main goal of this repository is to strengthen my Python fundamentals and learn how to write organized, reusable, and maintainable code using Object-Oriented Programming.

## 📚 Concepts Practiced

- **Classes and Objects** — Creating classes and working with objects.
- **Constructors** — Initializing objects using `__init__()`.
- **Encapsulation** — Protecting data using private attributes.
- **Inheritance** — Reusing properties and methods from parent classes.
- **Polymorphism** — Implementing different behaviors through method overriding.
- **Method Overriding** — Redefining parent class methods in child classes.
- **Static Methods** — Using methods that belong to a class.
- **Python Collections** — Working with lists and dictionaries.
- **Conditional Statements and Loops** — Implementing program logic.

## 💻 Mini Projects & Practice Programs

### 1. 🏦 Bank Account Management
- Deposit money into an account.
- Withdraw money with transaction validation.
- Check the current balance.
- Practice encapsulation using a private balance attribute.

### 2. 💰 Salary Calculator
- Store employee details and salary components.
- Calculate gross salary and annual salary.
- Find the highest salary component.
- Calculate the average of salary components.
- Practice inheritance using employee and salary classes.

### 3. 🎓 Student Report Card
- Store student details and subject marks.
- Calculate average marks.
- Check pass or fail status.
- Generate a basic student report card.
- Practice encapsulation and static methods.

### 4. 💳 Payment System
- Implement different payment types, such as credit card, UPI, and cash.
- Use inheritance and method overriding.
- Understand polymorphism through a common payment interface.

### 5. 🔔 Notification System
- Create email, SMS, and push notification classes.
- Use a common notification base class.
- Practice inheritance and polymorphism.

### 6. 📐 Shape Area Calculator
- Calculate the area of rectangles and circles.
- Implement a common base class.
- Practice method overriding and polymorphism.

### 7. 🛍️ Product Pricing System
- Represent physical and digital products.
- Calculate final prices for different product types.
- Practice encapsulation and inheritance.

### 8. 📚 Library Management Practice
- Represent books, magazines, and DVDs.
- Implement information methods for different item types.
- Practice inheritance and method overriding.
